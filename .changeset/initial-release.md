Full rewrite of openCPQ for React 19. TypeScript-first, zero runtime
dependencies, headless components with `cpq-*` class names, dual ESM +
`.d.ts` build, modernised `Root` and `EmbeddedRoot` shells built as
function components with `useReducer`. The `Type` / `Node` visitor pattern
is preserved.
